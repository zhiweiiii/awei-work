# 架构与项目窗口

awei-work 是面向 Claude Code / Codex 的 Windows 终端工作区，本机项目与独立 SSH 连接分别管理。Rust/Tauri 负责系统访问，React webview 负责界面；不内置另一套 AI agent 运行时。

## 代码入口

- `src/app/App.tsx`：连接模块、协调项目与窗口，不放领域实现。
- `src/modules/terminal/`：PTY 桥接、xterm、分屏和输入策略，详见 [终端](terminal.md)。
- `src/modules/spaces/`、`tabs/`：分组、标签和持久化。
- `src/modules/editor/`、`explorer/`、`markdown/`：文件、编辑和预览。
- `src/modules/source-control/`、`git-history/`：Git 界面；原生实现位于 `src-tauri/src/modules/git/`。
- `src/web/`、`src-tauri/src/modules/web/`：手机页面与桥接，详见 [手机端](mobile.md)。
- `src-tauri/src/modules/sessions.rs`、`usage.rs`、`schedule/`、`gateway/`：agent 配套功能，详见 [Agent](agents.md)。
- `src/modules/settings/`、`theme/`、`lsp/`、`updater/`：配置及按需能力。

## 系统边界

文件、进程、网络、PTY 和 Git 操作通过 Tauri `invoke()` 或已授权插件执行。命令注册以 `src-tauri/src/lib.rs` 为准，不维护容易过时的重复命令目录。插件权限在 `src-tauri/capabilities/`，不能替代应用命令的参数、路径和工作区校验。

新增命令放入所属原生模块，阻塞 IO/进程等待进入 blocking 池；注册后补带类型的前端封装。沿用工作区授权、输入上限、超时和进程树回收。已有命令封装优先复用 `src/lib/native.ts`。密钥和用户正文不进入诊断日志。

## 分组、项目与窗口

顶部入口依次为“文件、版本、SSH”，只切换侧栏。SSH 连接列表与终端通过两个固定 portal 容器共享同一控制器，visible 只表示侧栏选择，workspaceId 表示右侧正在显示的 SSH 连接，不能混用；点击 SSH 标签不切右侧，连接成功才激活终端，脚本执行不改变右侧。侧栏切换保留终端 DOM 和会话，选择本机项目/文件才解除 SSH 视图。分组默认收起且可拖动，连接可排序和跨组移动，拖动不会触发点击。新建、编辑及删除集中在管理弹窗和连接右键菜单。“切换”仅管理本机项目，配置与凭据分开保存，见 [SSH 与文件传输](terminal.md#ssh-与文件传输)。

连接新建类型为 SSH/动态执行代码，旧记录缺少 kind 时仍视为 SSH，网页/本机程序记录在加载配置时转换为独立脚本。代码放用户数据目录 connection-scripts 或用户指定的 .mjs 文件，配置只存路径；每次执行创建独立 Node 进程，通过管道传递凭据与有界请求，Job Object 负责取消与子进程回收。脚本只在显式执行时加载，不因文件变化自动运行；界面用内容哈希保护外部 agent 的编辑，磁盘读写进入 blocking 池。接口说明随默认脚本目录生成 AWEI-CODE.md，详见 [动态执行代码](connection-code.md)。

浏览器连接已移除：不再生成扩展、不启动 Chrome 桥接、不执行网页步骤或 OCR，也没有浏览器状态/设置 IPC。Node 脚本保留 launch、日志、等待与凭据管道；旧脚本文件不改写，旧网页配置兼容迁移到停用提示脚本并保留 legacyEntry 元数据。

分组对应 Space，项目对应 terminal 标签，`useTabs` 是标签及活动 ID 的事实来源。文件、Markdown、网页、Git 窗口通过 `ownerTabId` 归属项目，并同时按 `spaceId` 隔离。

分组按钮在原菜单内向下展开项目，再点收起；仅展开不切换活动分组或项目，选择项目才切换其所属空间。顶部显示当前选中的项目及运行 agent 的项目，跨分组显示，图标仅为分组首字。打开文件、Git 或网页时仍保留所属项目，不重复显示。顶部按项目首次打开顺序从左到右排列，不提供手动拖动排序；切换、agent 状态变化及分组内拖动不改变顶部顺序。首次打开顺序随项目保存，旧记录缺失时按加载顺序补齐，不能还原旧版未记录的历史顺序。分屏任一面板运行 agent 即保留项目，未选中且 agent 退出的项目收纳回分组。

分组菜单内项目可拖动排序，行上半部插入前方、下半部插入后方；拖到分组标题或空列表则追加到该组，悬停标题自动展开。跨组移动同步迁移所属文件/Git/网页窗口并保存排序，不重启 agent；移动当前项目时活动分组随项目迁移，移动其他项目不切换当前项目。拖动使用窗口内 Pointer Events，不依赖 HTML 原生拖放；超过 6px 才开始拖动，松手不穿透为项目点击，支持 Escape 取消及列表边缘自动滚动。

顶部关闭表示停止并收纳：终止该项目所有面板的终端会话及 agent，保留项目、目录、分屏和文件窗口。收纳优先于当前选中常驻规则，状态随项目保存，重启不自动恢复其 agent。从分组、窗口栏或重新打开按钮进入时创建新终端，不重放旧命令；终端模式定时任务的旧绑定失效，需要重新绑定。

分组内“彻底关闭项目”删除项目记录，仍保留未关闭的文件窗口与草稿并解除归属；运行中的终端保留确认提示。最后一个项目也可关闭，空分组保持为空。顶部中键及右键关闭与顶部按钮一致；关闭快捷键在单面板项目时收纳，多面板时仍关闭当前面板。

底部窗口栏首项返回当前项目，其余按打开顺序排列。文件单击默认持久打开，不覆盖旧窗口；去重与显式预览槽只在当前项目复用。关闭活动文件优先同项目窗口，否则返回所属终端。文件树的打开标识使用同一作用域。

窗口栏按实际宽度关闭最旧的干净窗口，保留活动、最新和未保存窗口；保护项放不下时横向滚动。关闭前用最新作用域及 dirty 状态复核，隐藏的零宽度不触发驱逐。

## 持久化与恢复

空间状态保存标签、面板树、目录、文件归属及最近使用时间。旧版非本机分组元数据及其状态保留在原存储中，不加载、不自动恢复，也不转换成 Windows 项目；后续保存本机列表时合并保留这些旧记录。写入串行化，关闭前等待磁盘保存；失败保留窗口。恢复校验结构、枚举、重复 ID 和有界面板树，损坏记录不被默认值覆盖。

重启跨分组暖启动最近 5 个非私密项目，其余保持冷标签。每个项目只自动恢复上次活动面板已确认的 Claude/Codex 会话，不按最新历史猜测，也不重放消息。旧版无会话身份的项目需升级后先运行会话并正常保存，详见 [Agent](agents.md)。

## 文件、媒体与 Git

文件栏顶部保留原目录名作为文件页签，在其与操作按钮之间增加“搜索结果”页签；选中采用与顶部“文件/版本”一致的圆角浅底色。输入搜索自动切到结果页，切回文件页保留关键字、结果及目录展开状态；切换项目清空搜索，旧目录或旧关键字的异步回复不回填。刷新按钮作用于当前页，点击目录结果展开并定位文件树，点击正文结果打开对应行。

文件名、相对路径及正文统一按文字包含匹配，忽略大小写，单个汉字也可搜索。空格、重复空格和标点按原文处理，不解析正则、分词或跳字匹配；路径搜索兼容 Windows 分隔符。输入有防抖，后端保留取消、结果数、遍历预算、忽略规则及正文文件 5 MiB 上限；不扫描构建依赖、隐藏或二进制正文。文件名完全匹配优先，其次文件名包含和路径包含；正文按目录与行号稳定返回有界结果。

文件树中的仓库根文件夹在名称后显示 `（当前分支）`，顶部文件页签也显示其所在仓库的分支；普通子目录和文件不重复标注，分离 HEAD 明确显示。复用已发现仓库的分支快照，不增加逐目录 Git 查询；独立于 Git 颜色标记，切换分支或项目同步更新，规范路径兼容目录别名和 Windows 大小写。合并单层目录在仓库根处停止，避免隐藏仓库名称及分支归属。

编辑缓冲统一 LF，保存还原原始 EOL。普通读取限 10 MB，明确继续读取最多 50 MB，大文件降级语法/LSP。保存与格式化串行，按文档代次拒绝旧结果，mtime 冲突要求确认；这不是外部进程事务锁。

图片、视频、音频和 PDF 沿用 editor 标签，由 `EditorStack` 按扩展名选择 `MediaPane`。路径按所属工作区 canonicalize，再用 asset 协议加载，不完整读取媒体正文或启动文本编辑器。失败有提示和手动系统打开入口，隐藏音视频暂停；视频解码取决于 WebView2。

文件事件携带执行环境，目录树、编辑器和 Git 只重读匹配范围。监听通过注册句柄释放，不依赖目录仍存在；事件溢出明确 rescan。Windows 路径身份统一大小写及分隔符，保留 UNC 支持。

Changes 按目录树显示，公共父目录只出现一次，无文件的单子目录链压缩显示，分叉处展开子目录。父目录计数包含后代文件，任意目录可折叠，根目录文件独立；多仓库同名目录不合并。提交与分支操作固定仓库/环境，并用同步门闩拒绝重复操作；切换后旧回复不回填。检出后强制刷新 HEAD 与分支列表。

拉取只允许快进；推送前复核 HEAD、分支及 upstream，批量失败逐仓库报告。改写当前提交说明使用 `amend --only` 保持暂存区，不擅自 abort 或重置外部冲突。差异统一 LF，CodeMirror 配置 `scanLimit: 10000`、`timeout: 200`，预算耗尽允许粗略结果。差异缓存有范围身份及 6 项/8 MiB 双预算。

## 其他按需能力

LSP 没有根标记就不启动，每个服务器最多 4 个会话，闲置 3 分钟回收；启停代次、文档身份与 transport 身份隔离。初始化失败清理并退避。Java 已启用时，首次进入项目会串行准备尚未完成的索引，不必先打开 Java 文件；已有完成记录的项目不预启进程，需要编辑时才加载缓存并核对变化。达到会话上限时等待空闲服务释放，正在初始化的项目不因切换项目被回收。

Java 的 Ctrl+单击/F12 先查定义，仅目标为接口或抽象声明时继续查实现，避免普通方法多发一次实现查询；单个直接跳转，多个显示候选，没有实现时回到定义。在方法声明处点击则查引用，Mapper 声明优先跳转对应 XML。Ctrl+F12 只查实现，Alt+F12 或 Ctrl+Alt+单击只查定义，Shift+F12 查引用。跨文件保留行和列，首次加载编辑器后继续定位，Ctrl+左右方向键在当前项目的跳转历史中前进后退。Java 项目根优先识别实际包含子模块的 Maven 聚合 POM 或 Gradle settings，遵守 Git、用户目录及已有工作区授权边界；不会扩大授权或为每个子模块重复启动服务。

Java 跳转成功结果按语言服务会话缓存，仅保留标题、URI、行列。每项目最多 2,048 条，按估算数据量限制 1 MiB，先达到任一上限即 LRU 淘汰；一条对应一个源位置及跳转方式，可包含多个候选，并非一个文件。单条最多 128 KiB，30 秒到期；不缓存空结果、异常、源码或语法树，不写磁盘、不增加轮询。缓存键区分文件、位置和跳转方式。Java 文档变化、未保存 XML 编辑、现有文件事件及索引状态通知清除结果，代次隔离阻止旧查询重新填充缓存或导航；30 秒上限也限制现有监听范围外修改造成的旧结果。上述预算不等于 JavaScript 堆占用，且不包含 JDTLS 自身索引。

内置 JDTLS 的索引目录按项目完整路径隔离，避免同名项目冲突。握手完成后仍等待 Java 的项目初始化完成通知，当前文件的状态栏显示索引状态；初始化时点击跳转立即提示，已连接服务的请求在就绪后继续，同位置重复点击合并，编辑、离开编辑器或关闭文件取消旧跳转。启动期间的编辑使用最新快照打开文档，后续版本号严格递增。LSP 写入串行，配置/工作区请求只回复一次。首次启动按需下载并校验 Lombok 1.18.48，缓存后以 Java agent 加载，支持生成方法的语义诊断及导航；不改写用户依赖。下载失败保留普通 Java 功能并明确提示，未导入的依赖仍可能没有结果；特殊虚拟依赖源码不冒充本地文件打开。

Java 导入在默认排除规则上增加 `.git/.idea/target/build/dist/out`，避免从这些目录发现额外项目；资源刷新过滤 `.git/.idea/.metadata/node_modules`，引用查询不扫描依赖反编译源码。构建输出与构建工具登记的生成源码仍可被原项目使用，避免破坏生成类型的解析。上述配置收敛扫描及查询范围，不代表 JDTLS 仅索引业务代码：本机 1.60 的依赖与 JDK 类路径仍需索引，不通过移除依赖、删除正在使用的索引或改为语法服务来缩小空间。现有索引不会因这些配置立即缩小，实际减量需重新启动语言服务后测量。

Java 启动默认传入官方 `jdt.core.sharedIndexLocation`，公共目录为应用缓存下 `lsp/jdtls-shared`。各项目复用同一依赖的索引，源码、工作区和跳转结果继续按项目隔离，不能共用 `-data`。缓存身份及格式版本由 JDT 管理，不自行复制或合并 `.index`。显式指定共享路径时保持用户参数；默认目录创建失败提示并使用原项目索引。参数在下次启动 Java 语言服务时生效，旧项目目录保留，不自动删除或迁移；共享主要减少重复磁盘数据及重复工作，不合并各服务的 Java 堆。该机制在上游客户端仍标记实验性。

项目目录中的 `awei-project.json` 原子保存项目路径、首次创建、最近使用及索引完成时间，完成状态以 Java 服务实际就绪通知为准。重新打开沿用同一目录，不按终端 ID 或临时会话重建。普通关闭服务、应用确认退出以及主动删除缓存都先完成有时限的 `shutdown/exit`，再回收进程树；无响应、崩溃或系统强制终止不保证完成最后一次保存。源码或依赖改变时由 JDT 校验并更新，不把存在目录等同于当前索引已就绪。

设置 → 编辑器 → Java 索引缓存显示项目路径、索引完成时间、磁盘占用、文件数和使用状态，同时列出公共依赖缓存。手动刷新时统计，不增加常驻轮询。删除通过缓存 ID 定位应用拥有的目录，拒绝路径穿越和重解析目录；停止受影响的服务后删除，保留源码、凭据及其他缓存。共享缓存删除后，相关项目下次打开会重新准备依赖索引。服务启动与删除通过原生维护锁及缓存代次协调，旧启动请求不会重新启用刚删除的缓存；删除退出不记作崩溃，也不立即自动重启。旧版无项目记录的目录显示“旧项目缓存”，再次打开项目后补齐身份。

网页预览只接受 HTTP/HTTPS，拒绝凭据、控制字符及内部应用 origin；入口拒绝 iframe 内启动。Markdown 使用安全 HTML/协议过滤，项目文件链接重新校验后打开，不允许内容直接执行宿主操作。

设置启动时总是初始化，单窗口读改写串行，旧加载不覆盖新选择；跨窗口仍非事务。背景对象 URL、监听、动画和异步句柄均在切换/卸载时释放。
