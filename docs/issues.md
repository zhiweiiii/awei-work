# 限制与近期变更

## 1.1.0

本版集中收录 SSH 终端与 SFTP、独立连接脚本、Java 导航及持久化索引缓存、Git 文件夹暂存和文件树分支显示。公共 Java 依赖索引跨项目共享，项目缓存可在设置中查看和删除；正常退出先保存语言服务工作区。浏览器扩展、网页步骤与验证码 OCR 按后续要求移除，独立本机脚本保留。下列“未发布”条目为本版开发过程记录，以最终架构说明和本节为准。

前端 lint、类型、桌面/手机构建、体积与引用检查，以及 Rust fmt/clippy 已通过；隔离 Tauri/JDTLS 验证索引重用、退出保存、使用中删除及共享缓存失效，React/WebView2 验证缓存管理交互。完整业务项目、真实 SSH 服务器和安装升级的全部组合仍需实际使用验收。

这里只保留仍有效的限制、待验收事项和近期重要结论。详细设计见 [文档索引](README.md)，旧修复过程与逐文件审查记录从 Git 历史查阅，版本说明以 [GitHub Releases](https://github.com/zhiweiiii/awei-work/releases) 为准。

## 未发布：移除浏览器连接

按用户要求移除 Chrome 扩展设置、回环桥接、网页操作引擎、图片验证码 OCR 及相关 IPC/代码模板。动态 Node 脚本保留程序启动、日志、等待及凭据管道；SSH/SFTP、普通网页预览与旧脚本文件保留。旧网页记录仅兼容迁移，保留原元数据，不执行浏览器动作。前端 lint/类型与构建、Rust fmt/clippy 通过；未制作或覆盖安装桌面新版本。

## 未发布：Java 打开即退出

首次打开 Java 文件会准备 Lombok，新增 HTTPS 客户端早于更新检查或 Claude 网关初始化。reqwest 使用无默认加密提供者的构建，此时构造客户端会 panic，发布版 panic=abort 导致原生进程退出。已将 rustls ring 提供者统一安装到应用启动入口，删除网关内局部初始化，确保 Java、更新与其他 HTTPS 使用同一启动前提。Windows 两次退出记录均为 awei-work.exe 1.0.32 的 0xc0000409，冷进程最小复现得到“No provider set”，安装提供者后同一 HTTPS 客户端构造通过；未以异常捕获掩盖问题。

## 未发布：SSH 侧栏与文件夹暂存

SSH 改为只切换侧栏，去掉中间介绍页及顶部独立标题；保存凭据后点击直接连接，仍保留必要的密码及主机指纹确认。管理弹窗集中分组和连接增删改，连接右键菜单提供操作；分组默认收起，连接可排序、跨组拖动及悬停展开，拖动不连接、不执行脚本。右侧只在连接成功后切入 SSH，动态代码不切换右侧，迟到连接完成会断开而不抢占视图。

Changes 文件夹显示含子目录的三态复选框，批量暂存/取消暂存只影响所属仓库及目录，根目录文件直接显示、不再生成 (root) 分组。已用仓库外临时 Git 仓库验证新文件、删除文件、目录边界及跨仓库隔离。

本地 Windows WebView2 挂载实际 React 组件、模拟 IPC 验证默认收起、组内/跨组移动、悬停展开、拖动不执行、管理弹窗、连接右键菜单、保存凭据后直接连接、必要的指纹确认及迟到连接回收。前端 lint、类型与构建及 Rust fmt/clippy 通过。百佳华 VPN 的独立 IE 脚本已编写并通过语法及地址范围检查，尚未真实登录；浦房已在用户当前 Chrome 真实登录，并从资产列表的“招商测试环境3 → administrator → WEB”进入远程桌面，用户确认成功。

## 未发布：网页验证码与条件步骤

动态代码新增 `when` 条件，已登录时跳过登录步骤；`captcha` 步骤将同源图片交给 Windows 本机 OCR，只提取四位数字，不上传图片、不保存识别数据、不自动刷新或重试登录。失败保留当前页面，可手动继续；图片、请求和目标均有限制，取消及页面改变后不填写迟到结果。OCR 仅在此步骤被请求时启动，复用现有 windows 绑定版本，不引入远程识别服务或常驻轮询。

浦房独立脚本补齐验证码、登录和目标资产的 WEB 入口，不在脚本中保存账号密码。实际 Windows OCR 验证页面截图中的四位数字；本机未安装英文 OCR，因此使用系统已有识别语言并去除干扰线识别出的非数字。新版扩展协议为 2、扩展版本为 1.1.0，安装新包后需重新加载 awei-work 网页扩展。人工浏览器操作已验证目标远程桌面，脚本经 awei-work 扩展完整自动登录的联调仍需安装新包后验收；不将人工流程验证等同于脚本端到端通过。

## 未发布：Java 实现跳转

Java 索引新增完成记录和设置管理。启用 Java 后，首次进入项目会串行准备索引，已有完成缓存时不预启 Java 进程；项目目录长期保留，共同依赖共享。设置 → 编辑器列出项目、路径、占用、文件数、完成时间和使用状态，可刷新及单独删除项目/共享索引。删除先关闭使用该缓存的服务，阻止旧启动请求复活；删除缓存不改动项目源码，重新进入项目或打开 Java 文件时重建。

原应用退出直接终止服务，普通关闭还可能在 `exit` 消息写出前关闭 transport，导致最后一次索引保存不完整。现改为原生有时限的 shutdown/exit 流程；正常退出在窗口销毁前等待，失去响应再回收进程树。实际隔离 Tauri/JDTLS 验证首次准备、索引完成记录、同项目重启复用、活动缓存统计、使用中删除、非法身份拒绝及源码/共享缓存保留；实际 React/WebView2 配合模拟 IPC 验证设置列表、大小状态、取消及重复删除保护。隔离验证不代替用户完整业务项目及系统强制终止场景。

补充实际验证全服务退出保存、删除公共缓存后项目完成记录需重新准备。前端 lint、类型与生产构建、体积及引用检查，Rust fmt/clippy 通过。已构建本地 1.0.34 Windows x64 NSIS 安装包，5.46 MiB，包含上述索引缓存与设置管理；四份版本清单、主程序及构建记录版本一致。未覆盖安装当前桌面程序，尚未提交或发布到 GitHub。

Java 默认配置补上无关目录及构建目录的项目导入排除、元数据目录资源过滤，并关闭反编译依赖源码的引用搜索。保留依赖类路径和生成源码，确保业务代码的框架类型解析有前提。本机 JDTLS 1.60 不提供在保留依赖类型解析时仅关闭依赖 JAR 索引的普通配置；目录排除不能代替该能力，也未删除现有约 260 MiB 的项目索引。未重新生成用户项目索引，尚无空间减少的实测值。

Java 语言服务启动新增官方共享依赖索引参数，应用缓存 `lsp/jdtls-shared` 供不同项目复用依赖索引；每个项目的 `-data` 及源码身份保持独立。尊重显式共享路径，默认目录不可创建时提示并回退本地索引。下次启动服务生效，不操作运行中服务或删除旧缓存，不宣称不同 Java 进程共用全部内存。

本机实际 JDTLS 1.60 验证两个隔离临时项目先后启动，共用同一 JAR 的索引文件，第二个项目复用时文件大小与修改时间不变；两项目的业务实现跳转仍各自隔离，依赖方法悬浮信息可解析。Rust fmt/clippy 通过。该机制在上游客户端仍标记实验性，未以此验证代替用户完整业务项目或多服务并发首次建索引的验收；临时文件位于仓库外，未测量用户项目节省量。

跳转空结果不再固定附加“项目可能仍在索引”。仅语言服务报告索引中时提示“Java 项目正在索引”；就绪后返回空结果分别显示“未找到跳转目标”或“未找到实现”。启动提示与索引提示分开，初始化中继续等待现有就绪通知，不增加查询或轮询。

原跳转只发送 definition，接口类型的方法调用因此停在接口。现改为先解析定义，仅接口或抽象声明继续查实现，减少普通方法跳转的请求；唯一实现直接定位，多实现显示候选，无实现或不支持时回退定义。Ctrl+F12 只查实现，Alt+F12/Ctrl+Alt+单击只查定义，方法声明处默认查引用；Mapper 方法与 XML 支持映射跳转。修复首次创建编辑器时丢失目标定位，Ctrl+左右方向键按项目浏览跳转历史。去重 Location/LocationLink，跨文件保留列位置，文档改变、项目切换及旧列表选择不应用过期结果，不猜测 Spring 运行时 Bean。

Java 成功跳转结果新增项目隔离的内存 LRU：每项目最多 2,048 条、1 MiB 估算数据预算，先达到任一上限即淘汰最久未使用项；单条 128 KiB，30 秒到期。只存路径与位置，不存源码、不落盘。修改 Java、未保存 XML 编辑、收到相关文件事件或索引状态通知时清除，旧查询不能重填；没有监控到的外部变化最多受缓存到期时间约束。内存预算不包含 JDTLS，实际堆占用需计入对象开销。

仓库外 Windows WebView2 挂载实际 CodeMirror 与 LSP 客户端、模拟语言服务，验证重复跳转不再发送查询、普通方法仅查定义、接口继续查实现、项目隔离、Java/XML 编辑失效及查询期间变更后拒绝旧结果；同时验证缓存条数、LRU、到期与代次。前端 lint 与类型检查通过；不等同于用户完整 Java 项目的实机性能验收。

同时修复 LSP 消息并发写入可能使 didChange 与后续查询乱序、配置/工作区请求总返回 null，以及 Windows UNC URI 转换问题。Java 根识别 Maven 聚合模块与 Gradle settings，限制解析大小及向上范围，父目录不在工作区授权中时保留原模块根。

后续排查发现启动器按文件夹名分配索引、握手完成早于项目初始化，以及客户端丢弃启动期间编辑。改为完整项目路径索引、按 Java 初始化通知就绪、最新快照与递增文档版本；点击跳转立即提示索引状态，合并重复请求并取消失效跳转。修复配置请求被桥接和客户端重复回复。补上 Lombok Java agent，下载固定版本并校验缓存，不屏蔽真实错误；恢复当前文件的语言服务状态入口。

实际原生启动准备逻辑验证索引隔离、下载校验、缓存复用、损坏修复和含空格路径。真实 JDTLS 验证 Lombok @Data getter/setter、@Builder 无误报，生成 getter 可导航且不存在的方法仍报错。隔离 Edge 使用实际编辑器验证初始化点击提示、重复请求合并、就绪继续跳转、启动期间编辑、递增版本与离开编辑器后拒绝旧跳转；不等同于用户完整业务项目实机验收。

真实本地 JDTLS 导入临时双模块 Maven 项目，验证用户给出的接口方法调用：定义返回 IFdzcNotifyService，implementation 返回 FdzcNotifyServiceImpl 及准确行列。隔离 Edge 使用实际客户端与 CodeMirror 验证默认跳转、显式接口、无实现回退、多实现选择、重复目标去重、编辑后拒绝旧回复、串行 IPC、配置/工作区响应及 UNC/Unicode URI；独立 Rust 执行实际根识别方法覆盖聚合、无关父项目、Git 边界、Gradle 和 XML 命名空间/实体。用户完整业务项目及所有依赖索引仍需实机验收，JAR 虚拟源码尚未实现独立展示。

## 当前限制

- 平台只有 Windows 本机；WSL 集成已移除，旧非本机分组及状态仍保留在存储中但不加载，不自动迁移到本机。
- 自动恢复最多最近 5 个非私密项目，每项目上次活动面板一个 agent。旧版本没有具体 UUID，升级后先运行会话并成功保存；不恢复私密项目，不自动新建对话。
- Web 使用明文 HTTP/WS，绑定所有网卡，必须在可信局域网/VPN 后使用，不直接暴露公网。
- asset scope 仍为 `**`，不是项目目录沙箱；收紧前需兼顾任意用户选择媒体、背景与 UNC 路径。
- 视频支持取决于 WebView2 实际编码能力，部分 MOV/MKV/AVI/HEVC 不能内嵌播放；失败提示后可手动系统打开。
- 手机选项与状态降级解析有启发式，CLI 界面变化可能影响识别。工具输出是有限预览，超限需桌面查看；过快输出可能断连重新同步，快照接缝可能短暂重复。
- 消息去重限同一 PTY 的有界缓存；跨重启/刷新不保证恰好一次。定时任务结果未知不自动重发，取消不能撤回模型请求；应用未运行或睡眠时不执行。
- 设置/主题跨窗口读改写、外部 Git 和文件进程没有严格事务隔离。mtime 检查不是文件锁，应用门闩不能撤销已开始的原生命令。
- 大文件、复杂差异和历史读取有资源预算，可能降级或明确拒绝，不把部分内容冒充完整内容。Git diff 预算耗尽仍可粗略比较。
- 当前默认手动更新；签名自动安装渠道未完成实际验收。安装提权与日常运行提权不是同一要求。
- 并行启动多个 agent 会增加 CLI 与必要活网格资源，渲染器预算不是全进程内存上限。开发缓存大小不等于安装包或运行占用。
